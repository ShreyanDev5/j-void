# J-Void

A distraction-free, in-browser Java editor for practicing coding interview patterns. Built as the companion editor for [Shreyan's Arc](https://shreyans-arc.vercel.app/), a NeetCode-style DSA roadmap.

## Features

- **Distraction-Free Editor**: In-browser Monaco editor configured with custom warm themes, clean syntax highlighting, and instant reset.
- **Curated Problem Bank**: 58 classic DSA problems across 17 patterns, paired directly with [Shreyan's Arc](https://shreyans-arc.vercel.app/).
- **Allman Formatting**: Method signatures and starter templates structured with Allman braces.
- **Gutter Bookmarks**: Click line numbers to pin visual bookmarks that stay synced as code changes.
- **Responsive Layout**: Warm dark and light modes with a mobile-friendly problem drawer.

---

## Tech Stack

- **Frontend**: React, Monaco Editor (`@monaco-editor/react`), Vite, CSS
- **Deployment**: Vercel

## Getting Started

```bash
git clone https://github.com/ShreyanDev5/j-void.git
cd j-void/frontend-app
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.
